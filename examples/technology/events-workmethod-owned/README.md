# Workmethod-owned event registration

Use this owner when `FourPointApproach` must be available only for the Ultrasonic NDT Point workmethod.

Install `PointWorkMethod.py` together with both scripts from [`event-compute-common`](../event-compute-common/). Merge the callbacks into the selected R2026.1 workmethod script and confirm the Point workmethod is actually represented by the target template. Do not install the technology-owned variant at the same time.
